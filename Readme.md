# Guess The Error

There is an amazing api which has images for each request error we get so I turned it into a guessing a game in which you'll be given a random image of cat or dog ( there are two different modes ) with 4 options and one of them is the correct answer. 

## Hints
There are hints aswell which you can get if you're not getting what the image is trying to show. the hints are ai generated so sometimes they might not work if my hackclub ai usage quota surpassed hehe.

Demo Version :- https://guess-the-error.netlify.app
